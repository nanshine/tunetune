# Visual understanding

Distinguish classification, detection, segmentation and visual reasoning; labels, annotation cost and metrics differ. Compare frozen pretrained features plus a head with partial or full adaptation and relevant strong foundation-model references. Test object size, rare cases and capture conditions. Split by subject, scene or acquisition source rather than correlated images, and pin resizing, normalization and augmentations. Public collections repeat one photo as crops, resizes and re-uploads, so check near duplicates across the split by image or feature similarity, not file names. When the output locates objects or people, score the locations, not only whether the image contains them.

Official starting points: [Transformers](https://huggingface.co/docs/transformers/en/training), [AutoGluon Multimodal](https://auto.gluon.ai/stable/index.html).

Map reviewed: 2026-11-03. Before execution verify current task support, model license, revision, platform compatibility, data requirements and resource estimates from the selected official sources. These examples are not a compatibility guarantee.
