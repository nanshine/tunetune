# Video

Distinguish temporal recognition, retrieval, vision-language understanding and generation. Compare a frame-based baseline when appropriate, then methods that can capture temporal information. Verify frame sampling, duration limits, resolution, decoding and hardware requirements. Split by source video, scene or person, never adjacent random frames. For generation measure temporal consistency and task compliance as well as visual quality; retain clips and sampling conditions.

Official starting points: [Transformers video classification](https://github.com/huggingface/transformers/blob/main/docs/source/en/tasks/video_classification.md), [Diffusers](https://huggingface.co/docs/diffusers/main/en/training/overview).

Map reviewed: 2026-11-03. Before execution verify current task support, model license, revision, platform compatibility, data requirements and resource estimates from the selected official sources. These examples are not a compatibility guarantee.
