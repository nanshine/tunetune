# Workflow characters

These transparent PNGs were generated with the built-in imagegen tool using the TuneTune hero as a style reference. The workflow SVGs embed the optimized PNGs so they also render in image contexts that cannot load external resources; all text, cards, lines and arrowheads are SVG code.

Shared prompt: “A single isolated character cutout for a small README SVG diagram, transparent background with real alpha; simple cream fill, thick charcoal outlines, cobalt blue accent; playful minimal cartoon, readable at 72 pixels; no text, scenery or extra objects.”

Subjects:

- `user.png`: a friendly human bust, short dark hair, dot eyes, cream shirt and blue collar; clearly distinct from the robot and ghost.
- `agent.png`: a friendly robot bust, rounded rectangular cream head, blue eyes and a small antenna.
- `ghost.png`: the TuneTune hero's hooded ghost, simplified, preserving its tongue-out smile, drawstrings and wavy bottom, with one hand raised.

The generated files were resized to fit 256 × 256 pixels with alpha preserved. When replacing a character, update its embedded PNG in both `workflow-en.svg` and `workflow-zh.svg`.
