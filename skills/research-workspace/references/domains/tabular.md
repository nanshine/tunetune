# Tabular models

Start with a task-appropriate linear or tree baseline; investigate boosting, ensembles and tabular pretrained models when sample structure and evidence justify them. Choose metrics for calibration, class imbalance, missing values and decision cost, not accuracy alone. Split by entity or origin when rows share people, devices or processes. A large language model is not automatically a stronger tabular reference.

Official starting points: [scikit-learn](https://scikit-learn.org/stable/), [AutoGluon](https://auto.gluon.ai/stable/index.html).

Map reviewed: 2026-11-03. Before execution verify current task support, model license, revision, platform compatibility, data requirements and resource estimates from the selected official sources. These examples are not a compatibility guarantee.
